Proyecto final - Mi portfolio personal

  1. Crear un header con tu nombre y menu de navegacion.
  2. Anadir seccion "Sobre mi" con texto corto.
  3. Crear seccion "Proyectos" con lista o tabla.
  4. Insertar una galeria de 3 imagenes con figure y figcaption.
  5. Incluir formulario de contacto completo.
  6. Cerrar con footer y enlace de correo.
