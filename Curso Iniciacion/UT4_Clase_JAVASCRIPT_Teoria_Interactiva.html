0) Introduccion a JavaScript

Idea clave: JavaScript da interactividad a la web. Lee elementos, responde a eventos y cambia el contenido de la pagina. 
// Patron basico
boton.addEventListener("click", function () {
  caja.textContent = "He cambiado el contenido";
});

0.1) Donde situar la etiqueta script

Recomendacion: usar un archivo externo en el <head> con defer, o poner el script al final del <body>. 
<head>
  <script src="app.js" defer></script>
</head>

<body>
  ...
  <script src="app.js"></script>
</body>

1) Diferencias entre var y let

Idea clave: var tiene alcance de funcion y let tiene alcance de bloque. 
if (true) {
  var curso = "JS";
}
console.log(curso); // funciona

if (true) {
  let modulo = "DOM";
}
console.log(modulo); // error

1.1) Hoisting

Idea clave: una funcion declarada se puede usar antes; con var aparece undefined; con let aparece error. 
console.log(miVar); // undefined
var miVar = "hola";

console.log(miLet); // error
let miLet = "hola";
Pulsa un boton para ver el caso.
