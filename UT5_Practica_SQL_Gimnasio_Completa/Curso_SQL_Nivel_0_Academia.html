Practicas guiadas del gimnasio

          

            Estas tarjetas resumen lo que debes saber hacer. Son el puente entre el archivo del alumno y las soluciones.
          

        

      


      

        

          
Practica 1: Listar alumnos

          
Empieza con un `SELECT` sencillo y añade `ORDER BY` para no depender del orden interno de la tabla.

          
SELECT * FROM talumnos_g ORDER BY apellidos, nombre;

          

            Que debes vigilar
            
No asumas nunca que una tabla sale ordenada sola. Si quieres orden, lo pides con `ORDER BY`.

          

        


        

          
Practica 2: Filtrar actividades inactivas

          
Trabaja `WHERE` sobre una columna corta y controlada: `activa`.

          
SELECT descripcion FROM tactividades_g WHERE activa = 'n';

          

            Error tipico
            
Escribir `n` sin comillas o comparar con mayusculas si los datos estan en minuscula.

          

        


        

          
Practica 3: Actividad y profesor

          
Une actividades con profesores para dejar de ver ids sueltos y pasar a datos legibles.

          
JOIN tprofesores_g p ON p.idprofesor = a.idprofesor

          

            Idea clave
            
Un `JOIN` sirve para convertir claves foraneas en informacion que el usuario entiende.

          

        


        

          
Practica 4: Alumno + actividad + fecha

          
Aqui ya aparecen tres tablas. Es la consulta que de verdad enseña el modelo relacional.

          
talumnos_g + talu_activ + tactividades_g

          

            Caso limite
            
Si saltas la tabla `talu_activ`, el cruce entre alumno y actividad sera incorrecto.

          

        


        

          
Practica 5: Alumnos sin clases

          
Muy buena para aprender `LEFT JOIN` y detectar ausencias en una relacion.

          
WHERE ta.idalumno IS NULL

          

            Error tipico
            
No se usa `= NULL`. En SQL se usa `IS NULL`.

          

        


        

          
Practica 6: Quien hace mas actividades

          
Pasas de ver filas sueltas a resumir informacion con `COUNT`, `GROUP BY` y ranking.

          
COUNT(*) + GROUP BY + DENSE_RANK()

          

            Para que sirve
            
Sirve para pasar de consultas descriptivas a consultas de analisis, algo muy util en examen.

          

        

      

    


    

      

        

          
Errores tipicos y arreglo rapido

          

            Tener estos fallos visibles ahorra mucho tiempo en clase porque son exactamente los bloqueos que aparecen al empezar.
          

        

      


      

        

          
Insertar antes de crear

          
Si intentas ejecutar la carga antes de la creacion, Oracle no encontrara las tablas.

        

        

          
Hacer JOIN directo

          
No unas `talumnos_g` con `tactividades_g` sin pasar por `talu_activ`.

        

        

          
Olvidar el COMMIT

          
Si no confirmas la carga, luego parece que faltan datos aunque el script se haya ejecutado.

        

        

          
Comparar con NULL mal

          
`= NULL` no funciona como se espera. Debes usar `IS NULL` o `IS NOT NULL`.

        

        

          
GROUP BY incompleto

          
Si muestras columnas no agregadas, deben aparecer tambien en el `GROUP BY`.

        

        

          
Confundir HTML con Oracle

          
El laboratorio es de apoyo. La validacion final de la practica sigue siendo Oracle con los scripts `.sql`.
